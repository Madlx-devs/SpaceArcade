# 🚀 Space Arcade

A **2D space shooter game** built in Java.

**SpaceArcade** is a retro-style arcade shooter created using **Java Swing** and **Java 2D graphics**.
The project is mainly built for fun and experimentation while exploring **game architecture, collision systems, and performance optimizations like object pooling**.

---

# 🎮 Features

* Classic **arcade space shooter gameplay**
* Player spaceship with shooting mechanics
* Enemy ships
* Bullet **object pooling system**
* Basic **collision detection**
* Lightweight **Java Swing rendering**

---

# 🛠 Tech Stack

* **Java**
* **Java Swing**
* **Java 2D Graphics**

---

# ▶️ Running the Game

### 1. Clone the repository

```bash
git clone https://github.com/madlx-devs/spaceArcade.git
```

### 2. Navigate into the project

```bash
cd spaceArcade
```

### 3. Compile and run

```bash
javac Main.java
java Main
```
